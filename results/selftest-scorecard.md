## Scope detection

A run that passes the verifier but edits a file outside the allowed set must still be flagged, not scored as a pass.

| check | value |

Correct behaviour: verifier passed yes, scope_violation yes, verified_pass no. A passing verifier does not rescue an out of scope edit.
